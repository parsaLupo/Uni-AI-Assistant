# 13 — Project Scope

## MVP

### Must have

- authentication
- student profile
- courses
- prerequisites
- professors
- academic terms/calendar
- course offerings
- schedules
- exams
- announcements
- admin management
- document upload/versioning
- RAG ingestion
- RAG retrieval
- AI assistant
- citations
- conversations/history

## Phase 2 / advanced

- deterministic course eligibility engine
- schedule conflict detection
- smart course selection explanation
- notifications
- analytics improvements

## Future ideas

- voice input/output
- performance analytics
- recommendation model
- integration with official university systems when authorized

## Scope control rule

Every requested feature must be classified as:

- MVP
- Post-MVP
- Out of Scope

before implementation begins.
