# Phase 07 — Document Management

## Objective
Create the admin-controlled document lifecycle that feeds RAG.

## Tasks
- Document model and metadata.
- Upload endpoint.
- Admin UI.
- Version/status handling.
- File validation.
- Processing state.
- Document detail and audit information.

## Acceptance criteria
- [x] Admin can upload an allowed PDF.
- [x] Invalid/oversized files are rejected.
- [x] Document metadata is persisted.
- [x] Active/inactive/version state is visible.

## Agent execution contract

Before implementation, read `AGENTS.md` and all documents referenced by this phase. Do not start later phases unless explicitly instructed.

At completion, report changed files, tests run, migrations, acceptance criteria status, and known limitations.
