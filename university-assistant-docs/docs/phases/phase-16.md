# Phase 16 — Deployment and Release

## Objective
Make the application deployable and document the release process.

## Tasks
- production Docker configuration
- reverse proxy/HTTPS
- environment configuration
- database migration process
- backups
- health checks
- logging
- smoke tests
- release documentation

## Acceptance criteria
- [ ] Production environment starts from documented steps.
- [ ] HTTPS is enabled.
- [ ] Database backup exists and restore is tested.
- [ ] Health endpoint is monitored.
- [ ] Smoke tests pass after deployment.

## Agent execution contract

Before implementation, read `AGENTS.md` and all documents referenced by this phase. Do not start later phases unless explicitly instructed.

At completion, report changed files, tests run, migrations, acceptance criteria status, and known limitations.
